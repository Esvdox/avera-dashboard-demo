# Сводка компании — утверждённая реализация, 09.11.2026

Референс: последний утверждённый макет сводки и карточка прибыли пользователя. Одна колонка, пять блоков в фиксированном порядке: финансовый результат; заказы и исполнение; деньги и обязательства; команда; продуктовый портфель. Внутри блока компактные значения/дельты и один переключаемый график. Деньги — без графика. Максимум четыре графика на странице. Обзор и Сравнение объединены, старые ссылки #comparison ведут к сводке.

Оформление: существующие темы AVERA, текст 12/15/18 CSS px, линии 1.5 px, отрицательные участки красные, положительные акцентные. Штатка и продукты — пары рядов на одной шкале. Утверждённые факты не заменять демонстрационными значениями. Незагруженные источники обозначать явным статусом, без нулей и фиктивных точек.

Данные: ОФР annual/nine переключаются внутри финансового блока, не смешиваются в дельте; маржинальность сделок не равна рентабельности чистой прибыли. Баланс — на дату, дебиторская только расшифровка. Штатные ставки — подтверждённые снимки. Продукты — только реестр AVERA_SKU_BASELINE, без выдуманного нуля прочих продуктов. Полная история с регистрации требует дополнительных источников; текущий диапазон не выдаётся за подтверждённый срок жизни ООО.

Приёмка: ровно пять секций; переключатели не создают карточек; корректный ноль/минус; один календарь; одинаковые данные при переходе со старых ссылок; 320/390/1280 px, обе темы; нет переполнений и ошибок JS. Публиковать только разрешённые агрегаты из текущего публичного набора.
