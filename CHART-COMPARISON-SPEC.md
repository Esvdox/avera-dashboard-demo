# ТЗ. Динамика и сравнение показателей

Референс — фото Сергея, растр 589 × 1280 px. Рабочий экран x≈82–507. Рамка и элементы просмотрщика исключены. Карточка x≈98–492, y≈290–644. Заголовок x≈114, y≈308. Поле графика x≈176–464, y≈395–564. Легенда под осью, y≈598–625. При условном viewport 390 CSS px это карточка около 362 px шириной, внутреннее поле около 15 px, поле построения около 155 px высотой. Замеры приблизительны. Доступа к исходным CSS и JS референса нет.

Переиспользовать токены AVERA, панели и переключатели из comparison.css, точки из comparisonData() и SVG из comparison.js. В режиме «Графики» добавить заголовок блока и переключатель «Периоды / Хронология». По умолчанию «Периоды». Каждый показатель — отдельная карточка. Внутри заголовок с единицей, ось Y, светлая сетка и легенда с датами под графиком. А — последнее сопоставимое наблюдение, Б — предыдущее. Цвета из AVERA, А сплошная, Б пунктир. Для одного факта на период показывать маркер с числом на общей позиции периода. Линии уместны при нескольких точках внутри периода. Выручка — январь–сентябрь 2026 и 2025, текучесть — полные 2025 и 2024 годы. Стартовый SKU — один датированный срез. Недостающие данные — НД. Дни, недели и месяцы добавлять при появлении данных нужной частоты.

«Хронология» сохраняет датированные наблюдения, отметки прихода и сегодня, прежнюю высоту блока. «Было / стало» сохраняет выровненные числа. Проверить обе темы на 320/390/1280 px, порядок А/Б, даты, отсутствие вымышленных точек, переключение режимов и фокус.
