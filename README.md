# AVERA — демонстрационный дашборд

Все значения вымышлены. Реальные источники и персональные сведения отсутствуют.

Главный экран: index.html — восемь показателей, сравнение с условной исходной точкой, три графика и раскрываемые рекомендации собственнику.

Подробные разделы прежнего прототипа сохранены в details.html с app.js и styles.css. Демонстрационные сценарии разных экранов относятся к указанным на них датам и не являются единой фактической отчётностью.

Открыть index.html в браузере. Сайт статический, сборка и внешние зависимости не требуются.
