# AVERA

Единое статическое приложение: index.html, hash-навигация по шести разделам, общая тема и модель data.js. Все значения вымышлены. Реальные источники не подключены.

owner.js и owner.css содержат обзор собственника и общий визуальный стиль. app.js — детализацию и маршрутизацию. details.html перенаправляет старые ссылки в единое приложение с сохранением раздела.

Финансовый результат за сентябрь, остатки на 30 октября, прогноз ФОТ за октябрь. Условная исходная точка — 1 июля, сравнение финансов — с закрытым июнем.

Проверка: `node check-dashboard.cjs` при доступном пакете Playwright и Chromium. При внешнем расположении пакета задайте `PLAYWRIGHT_MODULE`. Для проверки опубликованной версии задайте `AVERA_URL`. Проверяются переходы, возврат, история браузера, старые ссылки, общие показатели, сравнение и сохранение темы на ширинах 390 и 1280 пикселей.
