# Правила оформления AVERA

Для этого и последующих дашбордов в проекте использовать DESIGN.md и tokens.css как согласованный визуальный стандарт пользователя. Геометрия основана на десяти мобильных референсах: системный шрифт, компактные цифры, контурные иконки, отдельные округлые карточки, KPI в две колонки на телефоне, боковое меню.

Копировать цветовую палитру мобильных референсов запрещено пользователем. По последнему указанию использовать исходные цвета системы AVERA: светлая тема с синим акцентом #0759ef, тёмная с фоном #051428, карточками #0b1e36 и акцентом #02c4ee. Petrol / sage / copper палитра отклонена пользователем. Не возвращать прежние большие цифры и слитую сетку KPI.

Все разделы — единое приложение с общей темой и данными. Не связывать разные версии интерфейса ссылками на отдельные старые страницы. После изменений проверить навигацию, тему, обновление, историю браузера и мобильный вид. Проверка: check-dashboard.cjs, пакет Playwright доступен через PLAYWRIGHT_MODULE либо обычный require.
